## Критерии готовности проекта

- [ ] Все обязательные сценарии из задания реализованы и доступны через SPA.
- [ ] Обычный пользователь видит только своё хранилище; администратор может управлять любым.
- [ ] Файлы физически хранятся под уникальными именами, а скачиваются с оригинальными.
- [ ] Все закрытые API проверяют сессию и права; ошибки имеют корректные HTTP-статусы и JSON-формат.
- [ ] Публичная ссылка не раскрывает пользователя, путь к хранилищу или имя файла.
- [ ] Проект разворачивается с нуля по README и проходит тесты.
- [ ] `yarn validate` проходит полностью, frontend сохраняет 100% покрытия по четырём метрикам, а backend — не менее 80% с полным покрытием обязательных сценариев прав доступа.
- [ ] CI успешно проверяет проект, история состоит из небольших проверенных коммитов, рабочее дерево перед публикацией чистое и не содержит секретов.
- [ ] Публичный репозиторий и приложение на reg.ru доступны проверяющему.
